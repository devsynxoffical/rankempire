Guide

Website SEO checker: how to check any page's SEO basics

How to get the page sourceWhat the checker reportsCommon problems it findsGo deeper

This free website SEO checker reads a page's source code and reports the on-page basics: title, description, headings, images, links, canonical and structured data. Because you paste the source, it works on any page, including pages behind staging or login. This guide shows how to use it and read the results.

How to get the page source

Open the page in your browser, right-click and choose View page source, then copy everything and paste it into the checker. For pages built with JavaScript, compare this with what Google renders using the URL Inspection tool in Search Console.

What the checker reports

Title and description length, the number of H1 headings, heading order, images missing alt text, internal and external links, the canonical URL, robots directives and structured data types found on the page.

Common problems it finds

Two H1 headings, a canonical pointing to another page, a leftover noindex from development, images without alt text and descriptions that are missing or duplicated across pages. Each one is quick to fix once you know it is there.

For a scored report use the SEO score checker, for a full on-page audit use the SEO audit tool, and for site-wide issues book a free SEO audit.
